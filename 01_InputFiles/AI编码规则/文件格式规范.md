# 文件格式规范

本文档定义了本工程中 `.c` 源文件和 `.h` 头文件的编写风格与模板规范。

---

## 〇、生成规则

生成 `.c` / `.h` 文件时必须遵守以下规则：

1. **只生成空文件** — 不添加任何函数实现、结构体定义、宏定义、变量声明，仅可添加自身模块 `.h` 引用，其余 `#include` 一律不添加。文件头与版本信息保留。
2. **代码注释全英文** — 模板内的分隔注释、`@brief`、`@param`、`@retval`、行内注释等一律使用英文。
3. **分隔块足够，不用 Doxygen 分组** — 以 `/***...***/` 块注释分隔代码区域，禁止使用 `@defgroup`、`@addtogroup`、`@{`、`@}` 等 Doxygen 分组标记。
4. **模块名首字母大写** — 文件名与模块名采用 PascalCase（如 `LedControl.h`）。
5. **函数名格式** — `<ModuleName>_` + `动作(PascalCase)`，如 `LedControl_Init()`。
6. **分隔注释宽度统一** — 块注释总宽 65 字符，中间行文字居中。

---

## 一、通用规范

### 1.1 文件编码
- 所有源文件统一使用 **UTF-8** 编码。
- 行尾使用 **CRLF**（Windows）或 **LF**（Linux），团队内部统一。

### 1.2 缩进与对齐
- 使用 **4 个空格** 缩进，禁止使用 Tab 字符。
- `#define` / `#if` / `#endif` 等预处理指令顶格书写。

### 1.3 注释语言
- 模块注释、函数注释、变更记录使用**中文**。
- 行内注释可中英混用，以清晰表达为准。

### 1.4 命名约定

#### 模块名与文件名

- **模块名**：首字母大写的驼峰命名（PascalCase），如 `LedControl`、`UsartDriver`、`AdcManager`。
- **文件名**：与模块名一致，`.h` / `.c` 同名。如 `LedControl.h` / `LedControl.c`。

#### 函数命名

- **格式**：`<ModuleName>_` + `功能描述(PascalCase)`。
- 模块名与功能描述之间用 **一个下划线** `_` 分隔。
- 示例：`LedControl_Init()`、`LedControl_On()`、`LedControl_GetStatus()`。

#### 变量命名

| 类型 | 规则 | 示例 |
|------|------|------|
| 全局变量 | `g_` + 模块名(PascalCase) + `_` + 名称 | `g_LedControl_Config` |
| 静态变量 | `s_` + 模块名(PascalCase) + `_` + 名称 | `s_LedControl_Ready` |
| 静态函数 | `s_` + 模块名(PascalCase) + `_` + 功能 | `s_LedControl_GpioInit()` |
| 指针变量 | `p_` 前缀 | `uint8_t *pData` |
| 局部变量 | 驼峰命名，无前缀 | `ledId`, `tickCount` |
| 函数参数 | `p_` 前缀（指针），驼峰命名（值类型） | `pConfig`, `ledId` |

#### 类型与宏命名

| 类型 | 规则 | 示例 |
|------|------|------|
| 宏定义 | 全大写 + 下划线 | `#define LED_CONTROL_MAX_COUNT 8` |
| 模块类型 | 模块名(PascalCase) + 描述 + `_t` | `LedControl_Status_t`, `LedControl_Config_t` |
| 枚举值 | `模块名(全大写)_` + 描述 | `LED_CONTROL_STATUS_OK`, `LED_CONTROL_MODE_OFF` |
| 内部类型 | 同上，描述加 `Priv` 后缀 | `LedControl_PrivRuntime_t` |

## 二、`.h` 头文件模板

```c
/**
 ******************************************************************************
 * @file    <ModuleName>.h
 * @author  <author_name>
 * @version V1.0.0
 * @date    <yyyy-mm-dd>
 * @brief   <ModuleName> module header file
 ******************************************************************************
 */

/****************************************************************
 *                         Change Log
 ***************************************************************/
/**
 * Version  Date        Description
 * -------- ------------ ----------------------------------------------------
 * V1.0.0   <yyyy-mm-dd> [New] module created, basic functionality implemented
 * V1.1.0   <yyyy-mm-dd> [New] <feature description>
 *                       [Modify] <modification description>
 *                       [Fix] <bug description>
 */

/****************************************************************
 *                     Include Guard
 ***************************************************************/
#ifndef __<MODULE_NAME>_H__
#define __<MODULE_NAME>_H__

#ifdef __cplusplus
extern "C" {
#endif

/****************************************************************
 *                        Includes
 ***************************************************************/
#include "stm32f10x.h"
#include "<OtherModule>.h"

/****************************************************************
 *                         Macros
 ***************************************************************/

/** @brief module version */
#define <MODULE_NAME>_VERSION_MAJOR    1
#define <MODULE_NAME>_VERSION_MINOR    0
#define <MODULE_NAME>_VERSION_PATCH    0

/** @brief <macro brief description> */
#define <MACRO_NAME>                   <value>

/****************************************************************
 *                       Type Defs
 ***************************************************************/

/**
 * @brief <enum brief description>
 */
typedef enum {
    <MODULE_NAME>_STATUS_OK    = 0x00,  /**< <status description> */
    <MODULE_NAME>_STATUS_ERROR = 0x01,  /**< <status description> */
    <MODULE_NAME>_STATUS_BUSY  = 0x02,  /**< <status description> */
} <ModuleName>_Status_t;

/**
 * @brief <struct brief description>
 */
typedef struct {
    uint32_t <field1>;  /**< <field description> */
    uint16_t <field2>;  /**< <field description> */
    uint8_t  <field3>;  /**< <field description> */
} <ModuleName>_Config_t;

/****************************************************************
 *                 Global Variables
 ***************************************************************/

extern <ModuleName>_Config_t g_<ModuleName>_Config;  /**< <variable description> */

/****************************************************************
 *                Function Declarations
 ***************************************************************/

/**
 * @brief  <function brief description>
 * @param  pConfig : config parameter pointer
 * @retval <MODULE_NAME>_STATUS_OK   : success
 * @retval <MODULE_NAME>_STATUS_ERROR: failure
 */
<ModuleName>_Status_t <ModuleName>_Init(<ModuleName>_Config_t *pConfig);

/**
 * @brief  <function brief description>
 * @param  None
 * @retval None
 */
void <ModuleName>_Deinit(void);

/**
 * @brief  <function brief description>
 * @param  <param1> : <parameter description>
 * @param  <param2> : <parameter description>
 * @retval <return value description>
 */
<ModuleName>_Status_t <ModuleName>_DoSomething(uint32_t <param1>, uint8_t <param2>);

#ifdef __cplusplus
}
#endif

#endif /* __<MODULE_NAME>_H__ */

/******************************* EOF (End of File) ***************************/
```

```c
        return <MODULE_NAME>_STATUS_ERROR;

    g_<ModuleName>_Config = *pConfig;

    /* init hardware / state machine / variables */
    // ...

    /* mark init complete */

/**
 * @brief  <function implementation description>
 * @param  None
 * @retval None
 */

{
    s_<ModuleName>_Ready = 0U;

    /* release resources */
    // ...
}

 * @param  <param1> : <parameter description>
 * @param  <param2> : <parameter description>
 * @retval <return value description>

{
    /* check init state */
    if (s_<ModuleName>_Ready == 0U)
    {
        return <MODULE_NAME>_STATUS_ERROR;
    }

    /* business logic */
    // ...

    return <MODULE_NAME>_STATUS_OK;
}

/****************************************************************
 *              Static Function Definitions
 ***************************************************************/

/**
 * @brief  <private function description>
 * @param  <param> : <parameter description>
 * @retval None
 */
static void s_<ModuleName>_InternalFunc(uint32_t <param>)
{
    /* internal implementation */
    // ...
}

/******************************* EOF (End of File) ***************************/
```

## 四、变更记录格式说明

### 4.1 格式规范

变更记录统一放在文件头部注释块中，紧接 `@brief` 之后。采用**表格对齐**格式，包含三列：**版本**、**变更日期**、**变更描述**。

```
 * Version  Date        Description
 * -------- ------------ ----------------------------------------------------
 * V1.0.0   2026-08-09   [New] 模块创建，实现基本功能
 * V1.1.0   2026-08-15   [New] 添加新功能
 *                       [Modify] 优化实现
 *                       [Fix] 修复问题
 * V1.1.1   2026-08-20   [Fix] 修复另一个问题
```

### 4.2 列宽规则

| 列 | 宽度 | 对齐 | 说明 |
|------|------|------|------|
| 版本 | 8 字符 | 左对齐 | `Vx.y.z` 格式 |
| 变更日期 | 12 字符 | 左对齐 | `YYYY-MM-DD` 格式 |
| 变更描述 | 52 字符（可变） | 左对齐 | 以变更标签开头 |

> 同一版本有多条变更时，后续行**版本**和**变更日期**列留空，仅填写变更描述。

### 4.3 变更描述标签

| 标签 | 用途 | 示例 |
|------|------|------|
| `[New]` | 新增的功能、接口、文件等 | `[New] 添加 DMA 传输接口` |
| `[Modify]` | 对已有功能的变更 | `[Modify] USART 波特率默认值改为 115200` |
| `[Fix]` | Bug 修复 | `[Fix] SPI 从机模式接收丢字节` |
| `[Remove]` | 删除的功能或代码 | `[Remove] 废弃的 polling 方式读写接口` |
| `[Optimize]` | 性能优化、代码重构（非功能变更） | `[Optimize] 中断处理函数减少嵌套层级` |

### 4.4 版本号规则

版本号遵循 **语义化版本**（Semantic Versioning）：`V主版本.次版本.修订版本`

| 版本位 | 递增条件 |
|--------|----------|
| 主版本 (Major) | 接口不兼容的变更、模块重写 |
| 次版本 (Minor) | 新增向后兼容的功能 |
| 修订版本 (Patch) | 向后兼容的 Bug 修复、性能优化 |

## 五、注释规范

### 5.1 分隔注释

代码分段使用 `*` 填充的块注释，文字居中，宽度统一为 65 字符：

```c
/****************************************************************
 *                       Type Defs
 ***************************************************************/
```

### 5.2 文档注释

对类型和函数使用 `/** ... */` 格式的文档注释，描述其用途、参数和返回值：

```c
/**
 * @brief  module init
 * @param  pConfig : config parameter pointer
 * @retval STATUS_OK   : success
 * @retval STATUS_ERROR: failure
 */
```

| 标签 | 用途 |
|------|------|
| `@brief` | 简要说明 |
| `@param <name> : <desc>` | 参数说明 |
| `@retval <value> : <desc>` | 返回值说明 |

### 5.3 行尾注释

对枚举值、结构体字段使用 `/**< ... */` 格式的行尾注释：

```c
    STATUS_OK    = 0x00,  /**< success */
    uint32_t field;       /**< field description */
```

## 六、示例：LED 控制模块

### `LedControl.h`

```c
/**
 ******************************************************************************
 * @file    LedControl.h
 * @author  Zhang San
 * @version V1.0.0
 * @date    2026-08-09
 * @brief   LED control module header, provides LED init, on/off control and blink
 ******************************************************************************
 */

/****************************************************************
 *                         Change Log
 ***************************************************************/
/**
 * Version  Date        Description
 * -------- ------------ ----------------------------------------------------
 * V1.0.0   2026-08-09   [New] module created, LED on/off and blink implemented
 */

/****************************************************************
 *                     Include Guard
 ***************************************************************/
#ifndef __LED_CONTROL_H__
#define __LED_CONTROL_H__

#ifdef __cplusplus
extern "C" {
#endif

/****************************************************************
 *                        Includes
 ***************************************************************/
#include "stm32f10x.h"

/****************************************************************
 *                         Macros
 ***************************************************************/

#define LED_CONTROL_VERSION_MAJOR    1
#define LED_CONTROL_VERSION_MINOR    0
#define LED_CONTROL_VERSION_PATCH    0

/** @brief onboard LED count */
#define LED_CONTROL_MAX_COUNT        3

/** @brief LED index */
#define LED_CONTROL_ID_1             0
#define LED_CONTROL_ID_2             1
#define LED_CONTROL_ID_3             2

/****************************************************************
 *                       Type Defs
 ***************************************************************/

/**
 * @brief LED status enum
 */
typedef enum {
    LED_CONTROL_STATUS_OFF = 0x00,  /**< LED off */

} LedControl_Status_t;

/**
 * @brief LED blink mode enum
 */
typedef enum {
    LED_CONTROL_BLINK_SLOW   = 0x00,  /**< slow blink (1 Hz)   */
    LED_CONTROL_BLINK_FAST   = 0x01,  /**< fast blink (5 Hz)   */
    LED_CONTROL_BLINK_CUSTOM = 0x02,  /**< custom period       */
} LedControl_BlinkMode_t;

/**
 * @brief LED config struct
 */
typedef struct {
    uint16_t             blinkOnMs;   /**< blink on time (ms)  */

/****************************************************************
 *                 Global Variables

extern LedControl_Config_t g_LedControl_Config;

/****************************************************************

void              LedControl_Init(LedControl_Config_t *pConfig);
void              LedControl_Deinit(void);
void              LedControl_On(uint8_t ledId);
void              LedControl_Off(uint8_t ledId);
void              LedControl_Toggle(uint8_t ledId);
void              LedControl_BlinkStart(uint8_t ledId);
void              LedControl_BlinkStop(uint8_t ledId);

LedControl_Status_t LedControl_GetStatus(uint8_t ledId);

#ifdef __cplusplus
}
#endif

#endif /* __LED_CONTROL_H__ */

```

### `LedControl.c`

```c
/**
 ******************************************************************************
 * @file    LedControl.c
 * @author  Zhang San
 * @version V1.0.0
 * @date    2026-08-09
 * @brief   LED control module source, GPIO-based LED control with non-blocking blink
 ******************************************************************************
 */

/****************************************************************
 *                         Change Log
 ***************************************************************/
/**
 * Version  Date        Description
 * -------- ------------ ----------------------------------------------------
 * V1.0.0   2026-08-09   [New] module created, LED on/off and blink implemented
 */

/****************************************************************
 *                        Includes
 ***************************************************************/
#include "LedControl.h"

/****************************************************************
 *                         Macros
 ***************************************************************/

/** @brief LED pin port definitions */
#define LED1_PORT           GPIOE
#define LED1_PIN            GPIO_Pin_5
#define LED2_PORT           GPIOB
#define LED2_PIN            GPIO_Pin_5

/** @brief LED active low (modify per actual hardware) */
#define LED_ACTIVE_LEVEL    0

/****************************************************************
 *                       Type Defs
 ***************************************************************/

/**
 * @brief single LED runtime data struct
 */
typedef struct {
    uint8_t  active;        /**< 0=unused, 1=active   */
    uint8_t  blinking;      /**< 0=steady, 1=blinking */
    uint16_t blinkTimer;    /**< blink timer (ms)      */
    uint16_t blinkOnMs;     /**< on time (ms)          */
    uint16_t blinkOffMs;    /**< off time (ms)         */
    uint8_t  currentState;  /**< current level state   */
} LedControl_PrivRuntime_t;

/****************************************************************
 *                   Static Variables
 ***************************************************************/

static LedControl_PrivRuntime_t s_LedControl_List[LED_CONTROL_MAX_COUNT];  /**< LED runtime data table  */
static uint8_t                  s_LedControl_Ready = 0U;                   /**< module init complete flag */

/****************************************************************
 *             Static Function Declarations
 ***************************************************************/

static void s_LedControl_GpioInit(void);
static void s_LedControl_SetGpio(uint8_t ledId, uint8_t level);

/****************************************************************
 *                 Global Variables
 ***************************************************************/

/** @brief LED module global config */
LedControl_Config_t g_LedControl_Config;

/****************************************************************
 *              Global Function Definitions
 ***************************************************************/

/**
 * @brief  LED module init
 * @param  pConfig : config pointer, NULL for defaults
 * @retval None
 */
void LedControl_Init(LedControl_Config_t *pConfig)
{
    uint8_t i;

    /* default config */
    if (pConfig == NULL)
    {
        g_LedControl_Config.blinkMode  = LED_CONTROL_BLINK_SLOW;
        g_LedControl_Config.blinkOnMs  = 500;
        g_LedControl_Config.blinkOffMs = 500;
    }
    else
    {
        g_LedControl_Config = *pConfig;
    }

    /* init GPIO */
    s_LedControl_GpioInit();

    /* init runtime data */
    for (i = 0; i < LED_CONTROL_MAX_COUNT; i++)
    {
        s_LedControl_List[i].active       = 1U;
        s_LedControl_List[i].blinking     = 0U;
        s_LedControl_List[i].blinkTimer   = 0U;
        s_LedControl_List[i].blinkOnMs    = g_LedControl_Config.blinkOnMs;
        s_LedControl_List[i].blinkOffMs   = g_LedControl_Config.blinkOffMs;
        s_LedControl_List[i].currentState = LED_ACTIVE_LEVEL ? 0U : 1U;

        /* default all LEDs off */
        s_LedControl_SetGpio(i, LED_ACTIVE_LEVEL ? 0U : 1U);
    }

    s_LedControl_Ready = 1U;
}

/**
 * @brief  LED module deinit
 * @param  None
 * @retval None
 */
void LedControl_Deinit(void)
{
    uint8_t i;

    s_LedControl_Ready = 0U;

    for (i = 0; i < LED_CONTROL_MAX_COUNT; i++)
    {
        s_LedControl_List[i].active = 0U;
        s_LedControl_SetGpio(i, LED_ACTIVE_LEVEL ? 0U : 1U);
    }
}

/**
 * @brief  turn on specified LED
 * @param  ledId : LED index (LED_CONTROL_ID_1 ~ LED_CONTROL_ID_3)
 * @retval None
 */
void LedControl_On(uint8_t ledId)
{
    if ((ledId >= LED_CONTROL_MAX_COUNT) || (s_LedControl_Ready == 0U)) { return; }

    s_LedControl_List[ledId].blinking = 0U;
    s_LedControl_SetGpio(ledId, LED_ACTIVE_LEVEL);
}

/**
 * @brief  turn off specified LED
 * @param  ledId : LED index
 * @retval None
 */
void LedControl_Off(uint8_t ledId)
{
    if ((ledId >= LED_CONTROL_MAX_COUNT) || (s_LedControl_Ready == 0U)) { return; }

    s_LedControl_List[ledId].blinking = 0U;
    s_LedControl_SetGpio(ledId, LED_ACTIVE_LEVEL ? 0U : 1U);
}

/**
 * @brief  toggle specified LED
 * @param  ledId : LED index
 * @retval None
 */
void LedControl_Toggle(uint8_t ledId)
{
    if ((ledId >= LED_CONTROL_MAX_COUNT) || (s_LedControl_Ready == 0U)) { return; }

    s_LedControl_List[ledId].blinking = 0U;
    s_LedControl_SetGpio(ledId, s_LedControl_List[ledId].currentState ? 0U : 1U);
}

/**
 * @brief  start LED blink
 * @param  ledId : LED index
 * @retval None
 */
void LedControl_BlinkStart(uint8_t ledId)
{
    if ((ledId >= LED_CONTROL_MAX_COUNT) || (s_LedControl_Ready == 0U)) { return; }

    s_LedControl_List[ledId].blinking   = 1U;
    s_LedControl_List[ledId].blinkTimer = 0U;
    s_LedControl_SetGpio(ledId, LED_ACTIVE_LEVEL);  /* start from on state */
}

/**
 * @brief  stop LED blink
 * @param  ledId : LED index
 * @retval None
 */
void LedControl_BlinkStop(uint8_t ledId)
{
    if ((ledId >= LED_CONTROL_MAX_COUNT) || (s_LedControl_Ready == 0U)) { return; }

    s_LedControl_List[ledId].blinking = 0U;
    LedControl_Off(ledId);
}

/**
 * @brief  LED tick handler (call in 1ms timer ISR)
 * @param  None
 * @retval None
 */
void LedControl_TickHandler(void)
{
    uint8_t  i;
    uint8_t  currentLevel;
    uint16_t threshold;

    if (s_LedControl_Ready == 0U) { return; }

    for (i = 0; i < LED_CONTROL_MAX_COUNT; i++)
    {
        if ((s_LedControl_List[i].active == 0U) || (s_LedControl_List[i].blinking == 0U))
        {
            continue;
        }

        s_LedControl_List[i].blinkTimer++;

        currentLevel = s_LedControl_List[i].currentState;
        threshold    = currentLevel
                       ? s_LedControl_List[i].blinkOnMs
                       : s_LedControl_List[i].blinkOffMs;

        if (s_LedControl_List[i].blinkTimer >= threshold)
        {
            s_LedControl_List[i].blinkTimer = 0U;
            s_LedControl_SetGpio(i, currentLevel ? 0U : 1U);
        }
    }
}

/**
 * @brief  get LED current status
 * @param  ledId : LED index
 * @retval LED_CONTROL_STATUS_ON  : LED on
 * @retval LED_CONTROL_STATUS_OFF : LED off
 */
LedControl_Status_t LedControl_GetStatus(uint8_t ledId)
{
    if (ledId >= LED_CONTROL_MAX_COUNT) { return LED_CONTROL_STATUS_OFF; }
    return s_LedControl_List[ledId].currentState ? LED_CONTROL_STATUS_ON : LED_CONTROL_STATUS_OFF;
}

/****************************************************************
 *              Static Function Definitions
 ***************************************************************/

/**
 * @brief  init LED GPIO pins
 * @param  None
 * @retval None
 */
static void s_LedControl_GpioInit(void)
{
    GPIO_InitTypeDef gpioInit;

    /* enable GPIO clock */
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOE | RCC_APB2Periph_GPIOB, ENABLE);

    /* config LED1 (PE5) and LED2 (PB5) as push-pull output */
    gpioInit.GPIO_Mode  = GPIO_Mode_Out_PP;
    gpioInit.GPIO_Speed = GPIO_Speed_50MHz;

    gpioInit.GPIO_Pin = LED1_PIN;
    GPIO_Init(LED1_PORT, &gpioInit);

    gpioInit.GPIO_Pin = LED2_PIN;
    GPIO_Init(LED2_PORT, &gpioInit);
}

/**
 * @brief  set LED GPIO output level
 * @param  ledId : LED index
 * @param  level : target level (0=low, 1=high)
 * @retval None
 */
static void s_LedControl_SetGpio(uint8_t ledId, uint8_t level)
{
    s_LedControl_List[ledId].currentState = level;

    switch (ledId)
    {
    case LED_CONTROL_ID_1:
        GPIO_WriteBit(LED1_PORT, LED1_PIN, (BitAction)level);
        break;
    case LED_CONTROL_ID_2:
        GPIO_WriteBit(LED2_PORT, LED2_PIN, (BitAction)level);
        break;
    default:
        break;
    }
}
```

## 七、文件末尾规则

- 每个 `.c` 和 `.h` 文件的最后一行必须是：
  ```
  /******************************* EOF (End of File) ***************************/
  ```
- `EOF` 标记后需有一个空行（即文件以换行符结束）。

## 八、快速创建指南

新建 `.c` / `.h` 文件时，按以下步骤操作：

1. **确定模块名**：取一个首字母大写的 PascalCase 名称，如 `LedControl`、`UsartDriver`。
2. **替换模板中的占位符**：
   | 占位符 | 替换为 | 示例 |
   |--------|--------|------|
   | `<ModuleName>` | PascalCase 模块名 | `LedControl` |
   | `<MODULE_NAME>` | 全大写 + 下划线模块名 | `LED_CONTROL` |
3. 填写 `@author` 为实际作者名。
4. 填写 `@date` 为创建日期。
5. 在 `@brief` 中写模块一句话描述。
6. 在变更记录中填写初始版本号、日期和创建说明。
7. 函数命名规则：`<ModuleName>_` + `功能描述(PascalCase)`，如 `LedControl_Init()`、`LedControl_GetStatus()`。
8. 类型命名规则：`<ModuleName>` + `描述` + `_t`，如 `LedControl_Config_t`。
