# STM32F103VET6 详细规格参数

## 处理器

| 参数 | 值 |
|------|-----|
| 内核 | ARM Cortex-M3（ARMv7-M 架构） |
| 最大频率 | 72 MHz |
| 性能 | 1.25 DMIPS/MHz（90 DMIPS） |
| 单周期乘法 | 支持 |
| 硬件除法 | 支持 |
| NVIC | 嵌套向量中断控制器，最多 68 个可屏蔽中断通道，16 个优先级 |
| 系统定时器 | 24 位 SysTick 递减计数器 |

## 存储器

| 参数 | 值 |
|------|-----|
| Flash | 512 KB（单 Bank，2 KB 页擦除） |
| SRAM | 64 KB |
| 启动模式 | 支持从 Flash、系统存储器（Bootloader）或 SRAM 启动 |
| 预取缓存 | 2 个 64 位预取缓冲区 |

## 电源与复位

| 参数 | 值 |
|------|-----|
| 工作电压 (VDD) | 2.0V – 3.6V |
| 模拟供电 (VDDA) | 2.0V – 3.6V |
| 备份供电 (VBAT) | 1.8V – 3.6V |
| POR/PDR | 上电复位 / 掉电复位 |
| PVD | 可编程电压检测 |
| 低功耗模式 | 睡眠、停止、待机 |

## 时钟系统

| 时钟源 | 频率 |
|--------|------|
| HSE（外部高速） | 4 – 16 MHz |
| HSI（内部高速 RC） | 8 MHz（出厂校准） |
| LSE（外部低速） | 32.768 kHz |
| LSI（内部低速 RC） | ~40 kHz |
| PLL | 倍频至 72 MHz（从 HSE 或 HSI/2） |

## 模拟外设

| 外设 | 规格 |
|------|------|
| ADC1/2/3 | 12 位逐次逼近，1 Msps，16 个外部通道 + 内部通道（温度传感器、VREFINT） |
| 三重交错模式 | 3 Msps（三个 ADC 交替采样同一通道） |
| 转换范围 | 0V – VREF+（≤ VDDA，通常 3.3V） |
| DAC1/2 | 12 位缓冲输出，最高 1 Msps |

## 定时器

| 定时器 | 数量 | 特性 |
|--------|------|------|
| 高级（TIM1、TIM8） | 2 | 16 位，6 路互补 PWM，死区插入，紧急刹车 |
| 通用（TIM2–TIM5） | 4 | 16 位，IC/OC/PWM，正交编码器输入 |
| 基本（TIM6、TIM7） | 2 | 16 位，可驱动 DAC |
| 独立看门狗 (IWDG) | 1 | 独立于系统时钟 |
| 窗口看门狗 (WWDG) | 1 | 基于系统时钟 |
| SysTick | 1 | 24 位，内置于 Cortex-M3 核心 |
| RTC | 1 | 带日历和闹钟功能 |

## 通信接口

| 接口 | 数量 | 备注 |
|------|------|------|
| USART | 5 路 | 支持 ISO 7816、LIN、IrDA、调制解调控制 |
| SPI | 3 路 | 18 Mbit/s，其中 2 路可复用 I²S |
| I²C | 2 路 | SMBus / PMBus |
| CAN | 1 路 | CAN 2.0B Active |
| USB | 1 路 | USB 2.0 全速（12 Mbps） |
| SDIO | 1 路 | 支持 SD/SDIO/MMC/CE-ATA |

## FSMC（灵活静态存储控制器）

- 4 个片选区域
- 支持异步 SRAM、NOR Flash、NAND Flash、PSRAM
- 支持 8080/6800 并行 LCD 接口
- 仅 LQFP-100 和 LQFP-144 封装可用

## DMA

- 12 通道 DMA 控制器
- 支持存储器到存储器、外设到存储器、存储器到外设传输

## 调试

| 接口 | 说明 |
|------|------|
| SWD | 串行线调试（2 线：SWDIO + SWCLK） |
| JTAG | 标准 5 线 JTAG 接口 |
| ETM | 嵌入式跟踪宏单元（Cortex-M3 内置） |

## I/O 特性

- 80 个可编程 I/O 引脚（LQFP-100）
- 几乎所有 I/O 支持 5V 耐压
- 每个 I/O 可配置为：浮空输入、上拉/下拉输入、推挽输出、开漏输出、复用功能推挽/开漏
- 部分引脚支持 ADC 模拟输入

## 唯一标识

- 96 位唯一设备 ID（产品唯一序列号）
- 7 字节设备 ID 位于地址 `0x1FFFF7E8`

## 物理封装

| 参数 | 值 |
|------|-----|
| 封装 | LQFP-100 |
| 尺寸 | 14 × 14 × 1.6 mm |
| 引脚间距 | 0.5 mm |
| MSL 等级 | MSL 3（168 小时 floor life） |
| 环保 | RoHS3 / REACH 合规 |
