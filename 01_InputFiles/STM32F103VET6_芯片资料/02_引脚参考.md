# STM32F103VET6 引脚参考（LQFP-100）

## GPIO 端口分布

| 端口 | 引脚范围 | 说明 |
|------|----------|------|
| PA0–PA15 | 16 个 | 含 JTAG/SWD、USART1、ADC123、TIM2、USB |
| PB0–PB15 | 16 个 | 含 ADC12、TIM3/4、SPI2、I2C1、CAN、JTAG |
| PC0–PC15 | 16 个 | 含 ADC123、SDIO、I2S、USART |
| PD0–PD15 | 16 个 | 含 FSMC 数据/地址、USART、SDIO、CAN |
| PE0–PE15 | 16 个 | 含 FSMC 数据/地址、TIM1、SDIO 检测 |

## 启动模式（BOOT0 / BOOT1）

| BOOT0 | BOOT1 | 启动模式 |
|-------|-------|----------|
| 0 | X | 从主 Flash 启动（用户程序） |
| 1 | 0 | 从系统存储器启动（出厂 Bootloader，支持 USART1 下载） |
| 1 | 1 | 从内嵌 SRAM 启动（调试用） |

## 重要复用功能提示

- **USART1**：TX=PA9, RX=PA10（常用于串口下载/调试）
- **USB**：USBDP=PA12, USBDM=PA11
- **CAN**：CAN_TX=PB9 / PD1, CAN_RX=PB8 / PD0
- **I2C1**：SCL=PB6, SDA=PB7（常用）
- **SPI1**：SCK=PA5, MISO=PA6, MOSI=PA7, NSS=PA4
- **SWD**：SWDIO=PA13, SWCLK=PA14（调试器连接只需这两根线 + GND）
